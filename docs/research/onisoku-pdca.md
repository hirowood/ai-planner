# 鬼速PDCA の調査 (2026-09-30)

本人の言う「鬼束PDCA」= 冨田和成『鬼速PDCA』(クロスメディア・パブリッシング・2016-10・ISBN 9784844377498) と判断 (同名の本は見つからない)。図解版 (2018-06・第 7 章「継続力」を追加) もある。
一次 = 版元・著者・公式要約、二次 = 要約ブログ。**原書は読んでいない**ので、手順の正確な文言・数値は未確認として扱う。

## 構造 (因数分解)

`KGI → 課題 → KPI → 解決案 → DO (定量化 = KDI) → TODO` (二次・複数で一致)

| 階層 | 意味 |
|---|---|
| KGI | 期日と数値で表したゴール |
| 課題 | ゴールと現状のギャップを埋めるために取り組むこと。**優先度をつけて 3 つに絞る** (基準は 効果・時間・気軽さ。二次・3 つ目の選び方は未確認) |
| KPI | 課題ごとの中間指標 (頻繁に検証できるもの) |
| 解決案 | KPI を達成する大まかな方向 |
| DO / KDI | 具体的な行動と、その定量目標 (例「1 日 ○ ページ」) |
| TODO | 期日つきのタスク |

## 4 つの段

- **Plan (7 手順・二次)**: ゴールの定量化 → 現状とのギャップの定量化 → 課題の洗い出し → 優先度で 3 つに絞る → 課題を KPI 化 → 解決案 → 解決案の優先度
- **Do (二次)**: 解決案を DO に → 優先順位 → KDI 化 → TODO に分解 → 進捗を見ながら実行
- **Check**: KGI 達成率 → KPI 達成率 → KDI 達成率。未達は「なぜ」を繰り返す。うまくいった所を伸ばす「伸長」も見る (伸長は一次)
- **Adjust (A は Act ではなく「調整」・一次)**: 改善と伸長の 2 本柱。4 つの型 (二次): ①ゴールの調整 (中止・変更・継続) ②計画の大きな調整 (課題の中止・変更・追加) ③解決案・DO・TODO の調整 ④そのまま続ける → 直した階層から次の周へ戻る

## 速さと階層

- 大・中・小の PDCA の入れ子 (一次に「大・小のPDCA」)
- 振り返り: 「半週ミーティング」(一次)・図解版「3 日ごとの振り返り」(一次)。頻度の目安 (二次・1 件のみで不確実): KDI は毎日・KPI は 2〜3 週・KGI は月 1
- 「1 日の課題 3 つ」という記述は見つからない (「3 つ」は計画で課題を絞る数)。**毎日 3 つ決めるのは本人の運用案**として扱う
