# EXP-022 事前登録 — AI をコーチ・メンターとしてふるまわせる

Status: **登録済み (変更より前の commit)** / Date: 2026-09-30
仕様: `docs/product-spec.md` v2 §2 / 調査: `docs/research/onisoku-pdca.md`
きっかけ: 本人「AI はコーチのようにふるまい、アドバイスやメンターとして進めてください」
**この文書の数値・規則は、測った後で変えない。**

## 1. 仮説と範囲

- 動かしたい指標: KGI (本人の点数)
- H1: AI が「受け止め → 記録に基づく所見と助言 → 次の一歩の問い 1 つ」の形で返し、鬼速PDCA の考え方 (漠然を数と期日に・課題は 3 つに絞る・調整の 4 つの型) で導けば、本人は伴走されていると感じ、P・C・A を具体にできる
- 範囲: `/api/coach` のプロンプトの「役割」と「返答の形」の節だけ。記録の渡し方・約束 1〜6・JSON の形・保存は変えない
- 範囲外: 画面 (EXP-021 と同時に進むが、ファイルが別)・`/api/chat` (プロジェクトを選んでいない時の会話)

## 2. プロンプトに足すこと

- 役割: 伴走するコーチ・メンター。答えを押し付けず問いで気づかせる。要所で具体的な助言をする。できたことは記録から具体的に認める。温かく丁寧に、短く (返答は 300 字程度まで)
- 返答の形 (毎回): ①受け止め (一言) ②記録に基づく所見か助言 (根拠の記録を添える・約束 1) ③次の一歩の問い 1 つ (約束 3)
- 鬼速PDCA の考え方: 目標は期日と数値で (KGI)・漠然とした言葉には数と期日の入った言い直しを 2〜3 個示す・課題は効果・時間・気軽さで 3 つに絞る・振り返りでは達成率と「なぜ」、うまくいった所を伸ばす・調整はゴール / 課題 / 行動 / そのまま の 4 つの型から選ぶ

## 3. 実験室の判定

| 規則 | 条件 |
|---|---|
| L1 | プロンプトに「コーチ」「メンター」の役割・返答の形の 3 段・鬼速PDCA の考え方 (期日と数値・3 つに絞る・4 つの型) が入る (Gemini に渡った文をテストで確かめる) |
| L2 | 約束 1〜6・`<Records>` の枠・JSON の出力の指示は前と同じ文のまま (差分で確かめる) |
| L3 | `npm test` 全件成功・`tsc` 0 |

実験室の Gemini は差し替えなので、返事がコーチらしくなったかはここでは測れない。本人の利用で見る。

## 4. 本人の判定

| 判定 | 条件 |
|---|---|
| **定着** | 本人が「コーチらしくない」「助言が無い」を一番の困りごとに挙げず、返事に記録を根拠にした助言が 1 回以上ある (本人の一言で確かめる) |
| **巻き戻し** | 押し付けがましい・長すぎる・記録と違うことを言う、と本人が報告した (Human Gate) |
| **判定不能** | 14 日以内に使わない |
