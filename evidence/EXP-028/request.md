# EXP-028 事前登録 — AI が混み合っている (503) とき、自動で 1 回送り直し、だめなら「混み合っています」と出す

Status: **登録済み (変更より前の commit)** / Date: 2026-10-01
きっかけ: 本人 (点数 1)「新しいプロジェクトで『毎日の習慣を作りたい』を押したら『返事を受け取れませんでした』」。ログ: `/api/setup` で Gemini が 503 → アプリは 500。同時に `/api/setup/start` が 6.0〜6.5 秒かかり、傾向の一言が届く前に押していた。H-07 の残り (503 の扱い) が未着手だった
**この文書の数値・規則は、測った後で変えない。**

## 1. 仮説と範囲

- H1: Gemini の 503 を 1 回だけ自動で送り直せば、混雑の多くは本人に見えずに済む
- H2: それでも 503 なら、エラーではなく「混み合っています。少し待ってから送り直してください」と出して文を入力欄に戻せば、本人は次にすることが分かる (EXP-005 の 429 と同じ)
- H3: 傾向の分析中に「過去の傾向を分析中…」と出せば、届く前に押して一言を見逃すことが減る
- 範囲: `lib/gemini-retry.ts` (503 を 1 回だけ送り直す)・`/api/coach`・`/api/setup`・`/api/setup/start` で使う・503 の返し方・画面の 503 の扱いと分析中の表示

## 2. 決まり

- `withGeminiRetry(fn, wait = 800)`: fn が status 503 で失敗したら wait ms 待って 1 回だけ送り直す。429 やほかの失敗は送り直さない
- 2 回目も 503: `/api/coach`・`/api/setup` は 503 `{ error: "AI が混み合っています。少し待ってから送り直してください", kind: "overloaded" }`・`/api/setup/start` は既定の候補に 1 行添える
- 画面: 503 は notice に出し、送った文を入力欄に戻す (会話から外す)・エラーの表示は出さない
- 画面: 作成モードで傾向を読んでいる間、status に「過去の傾向を分析中…」

## 3. 実験室の判定

| 規則 | 条件 |
|---|---|
| L1 | `withGeminiRetry`: 1 回目 503 → 2 回目成功で結果を返す (2 回呼ぶ)・2 回とも 503 → 503 を投げる・429 は送り直さない (1 回だけ)・成功は 1 回 |
| L2 | `/api/setup`・`/api/coach`: 2 回とも 503 → 503 と kind overloaded・1 回目だけ 503 → 200 |
| L3 | `npm test` 全件成功・`tsc` 0・`next build` 成功 |
