# EXP-040 事前登録 — 日常のタスクを手帳に足し、時間割に入れる

Status: **登録済み (変更より前の commit)** / Date: 2026-10-02
きっかけ: 本人「ToDo は他にも日常のタスクを作れるようにして入れられるようにしてください」。本人の選択: **手帳に「日常」として** (KGI や KDI には紐づかない)
**この文書の数値・規則は、測った後で変えない。**

## 1. 仮説と範囲

- H1: プロジェクトに属さない日常のタスク (買い物・通院など) も手帳の日のページで同じ時間割に入れられれば、1 日の予定が 1 か所で見え、プロジェクトの ToDo の時刻を現実的に決められる
- 範囲: 日常のタスクの表・作る / 状態を変える / 時刻を変える / 消す・手帳の日のページの「日常の ToDo」と時間割への混在・週の表示に数
- 範囲外: 繰り返しのタスク・Google カレンダー・AI が日常のタスクを決める (AI には時間割の空きを知らせるだけ)

## 2. 決まり

データ: `daily_tasks` (id・owner・day date・title・start_time・end_time・status (todo / doing / done)・created_at・updated_at)。プロジェクトに属さない (持ち主ごと)

`lib/daily-tasks.ts` (純粋):
- `parseTaskInput(x, today)`: day は実在の日付 (過去 7 日〜未来 62 日)・title 1〜100 字・時刻は `parseSlot` と同じ (無くてもよい)・status 既定 todo
- `parseTaskPatch(x)`: title / status / 時刻のどれか 1 つ以上

API (`/api/tasks`): GET `?from=&to=` (62 日まで)・POST・PATCH `/api/tasks/[id]`・DELETE `/api/tasks/[id]`。すべて owner で絞る・他人 / 無い → 404

`/api/coach`: 今日の日常のタスク (題と時刻) を「#### 今日の日常の予定」として `<Records>` に入れる (今日の ToDo の時刻を決めるときに空きを考えるため)

画面 (手帳の日のページ):
- 「🏠 日常の ToDo」: 題・開始・終了・「足す」・各行に状態 (未実行 / 実行中 / 完了 のボタン)・消す (2 回押し)
- 時間割 (EXP-039) に日常のタスクも混ぜる (「[日常]」の印)
- 週の表示に日常のタスクの数
