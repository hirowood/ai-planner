# EXP-041 事前登録 — 右の列を「プロジェクト・スケジュール・手帳」の 3 つに分ける

Status: **登録済み (変更より前の commit)** / Date: 2026-10-02
きっかけ: 本人「プロジェクトはタスクなどを決めるところです。プロジェクトと手帳とスケジュールの欄を作成して、プロジェクトで PDCA 用のタスクを作る。作成したタスクはスケジュールに反映する。スケジュールでは今日の仕事や用事などタスクを作ったりする。手帳では今日の振り返りなどをする」
**この文書の数値・規則は、測った後で変えない。**

## 1. 仮説と範囲

- H1: 役割ごとに 3 つの欄 (決める・並べる・振り返る) に分ければ、どこで何をするかに迷わず、PDCA の P (タスクを決める)・D (予定に並べてやる)・C / A (振り返る) を順に回せる
- 範囲: 右の列のタブを 3 つ (📁 プロジェクト・📅 スケジュール・📒 手帳) にし、今ある部品を役割どおりに置き直す
- 範囲外: 新しい機能 (今ある部品の置き場所だけを変える)・左の会話

## 2. 決まり

| 欄 | 置くもの |
|---|---|
| 📁 プロジェクト | プロジェクトの一覧と選択・中のタブ「✅ タスク」(既定)・「📝 Plan」(階層と Plan の要点)・「📓 ノート」。✅ タスク = 今日の ToDo (KDI ごと・始める / 完了 / 判定待ち・状態) と ToDo の時刻の入力 |
| 📅 スケジュール | アプリ内のカレンダー (月の表・全プロジェクトの ToDo と日常の ToDo)・選んだ日のタイムスケジュール・選んだ日の「🏠 日常の ToDo」(仕事や用事を足す) |
| 📒 手帳 | 選んでいるプロジェクトの手帳 (日・週・月の切り替え・前後)・日のページは **振り返りだけ** (〇△×・良かったこと・明日はこうする・その日の ToDo の結果を見るだけ)・これまでのデータ。プロジェクトを選んでいなければ「プロジェクトを選ぶと手帳が開きます」 |

- 既定の欄は 📁 プロジェクト (タスクを決めるところから)
- `DailyView` に `parts` (`todos` / `reflection` / 既定は両方) を足し、プロジェクトの ✅ タスクは `todos`、手帳の日のページは `reflection` を使う
- 手帳の日のページの ToDo は見るだけ (始める・完了などのボタンは ✅ タスクに)
