# EXP-039 事前登録 — プロジェクトの ToDo を手帳の時間割 (アプリの中の予定表) に入れる

Status: **登録済み (変更より前の commit)** / Date: 2026-10-02
仕様: `docs/product-spec.md` §0 (PDCA の P は ToDo・Do: ToDo を予定に入れる)
きっかけ: 本人「プロジェクトが ToDo 作成で作成したものをスケジュールに予定を入れてください」。本人の選択: **アプリの中の予定表だけ** (Google カレンダーには入れない)
**この文書の数値・規則は、測った後で変えない。**

## 1. 仮説と範囲

- H1: 会話で決めた ToDo が時刻つきで手帳の日のページの時間割に並び、時刻を手でも直せれば、今日何時に何をするかが一目で分かり、Do に移りやすい
- 範囲: ToDo の時刻 (開始・終了) を保存する表・AI が ToDo を決めるときに時刻も聞いて入れる・手帳の日のページの時間割 (時刻のある ToDo を時刻順・時刻の無い ToDo は「時刻なし」)・時刻を手で入れる / 直す / 外す
- 範囲外: Google カレンダーへの自動登録 (EXP-030 の手動の「予定に入れる」はそのまま)・日常のタスク (EXP-040)・重なりの警告・通知

## 2. 決まり

データ: `item_slots` (item_id → plan_items 消したら消える・主キー・owner・start_time "HH:MM"・end_time "HH:MM")

`lib/slots.ts` (純粋):
- `parseSlot(x)`: `{start, end}` 両方 "HH:MM" で end > start → 時刻・両方 "" → 外す (null を返す印)・それ以外 → 不正
- `timetable(entries)`: 時刻のあるものを開始の早い順・時刻の無いものは後ろに「時刻なし」としてまとめる
- `slotLabel(start, end)`: 「09:00〜09:30」

API:
- `PUT /api/items/[id]/slot` `{start, end}`: 持ち主の ToDo だけ・時刻なら作るか上書き・両方 "" なら消す・ToDo でない / 他人 → 404・不正 → 400
- `GET /api/items/slots?projectId=`: 持ち主のプロジェクトの `{itemId, start, end}`

`/api/coach`:
- 今日の ToDo の段の決め方に「何時から何時にやるかも聞き、決まったら items / candidates の `start`・`end` (HH:MM) に入れる (決まらなければ空)」
- サーバは足した ToDo に時刻があれば `item_slots` にも入れる (持ち主・その ToDo)。返事の `itemsAdded` に時刻を足す

画面 (手帳の日のページ):
- 「🕘 時間割」: その日の ToDo を時刻順に (「09:00〜09:30 題 [状態]」)・時刻の無い ToDo は下に「時刻なし」
- 各 ToDo に開始・終了の入力と「時刻を入れる」(ラベルつき)・時刻のある ToDo に「時刻を外す」

| 規則 | 条件 |

| L1 | `parseSlot` (正しい時刻・end ≤ start・片方だけ・形違い・両方空は外す)・`timetable` (時刻順・時刻なしは後ろ)・`slotLabel` |

| L4 | 画面: 時間割の見出し・時刻順・時刻なしのまとまり・入力のラベル・外すボタン |

## 4. 本人の判定

| 判定 | 条件 |
|---|---|
| **定着** | 本人の使った日に時刻つきの ToDo が 1 つ以上あり、一番の困りごとに「いつやるか分からない」「予定が見えない」を挙げない |
| **巻き戻し** | 時刻が違う ToDo に入る・消える、と本人が報告した (Human Gate) |
| **判定不能** | 14 日以内に使わない |

## 6. 追記 (変更より前・2026-10-02・本人「Google カレンダーは規制などがあるため、誰でも汎用性があるため後で実装」「アプリ内にカレンダーとタイムスケジュールを作成」)

- Google カレンダーへの登録 (EXP-030 の「📅 予定に入れる ToDo」) は画面から外す (コードは残し、後で Google を実装するときに戻す)
- **タイムスケジュール** (`TimeSchedule`): 1 時間ごとの行 (6:00〜24:00 を既定・それより早い / 遅い予定があれば広げる) に、時刻のある ToDo と日常のタスクを置く。時刻の無いものは下に「時刻なし」。手帳の日のページと、右の列の「📅 カレンダー」タブの両方で使う
- **アプリ内のカレンダー**: 右の列の「📅 カレンダー」タブを、Google の予定の一覧から **アプリの中のカレンダー** に置き換える。月の表 (日付ごとの ToDo と日常のタスクの数) と、選んだ日のタイムスケジュール。**すべてのプロジェクト**の ToDo と日常のタスクを出す (どのプロジェクトかの印つき)
- API: `GET /api/items/schedule?from=&to=` (持ち主の全プロジェクトの、期日が期間の中の ToDo と時刻とプロジェクト名・62 日まで)
- L4 に足す: タイムスケジュールの時間の行と置き場所・カレンダーのタブの月の表と選んだ日・プロジェクトの印
