## 1. 仮説と範囲

- H1: チャットを目的ごとに分け、それぞれが自分の段だけを扱えば、話がそれず、1 つの会話が短く深くなり、決めることが早く決まる
- 範囲: プロジェクトごとの 5 つの会話 (consult・kgi・kpi・kdi・todo) の保存と読み出し・チャットの上のタブ・チャットごとの決め方 (段・足せるもの・変えられるもの)・「🆕 プロジェクト作成」は今の作る会話 (タブから始める)
- 範囲外: 自由に増やせるチャット・チャットの名前の変更

## 2. 決まり

会話 (`messages.thread`): `chat` (= 💬 壁打ち・相談・今までの会話はここに残る)・`kgi`・`kpi`・`kdi`・`todo`。`plan` はそのまま (古い Plan の会話)

`lib/threads.ts` (純粋):
- `COACH_THREADS = ["chat", "kgi", "kpi", "kdi", "todo"]`・ラベルと絵文字
- `threadStep(thread, items, today)`: その会話で決める段
  - chat・kgi → null (階層に足さない)
  - kpi → KGI の下の KPI (KGI が無ければ kgi の段 = 作るよう勧める)
  - kdi → KDI の少ない KPI の下の KDI (KPI が無ければ null・`have` は今の KDI の数)
  - todo → 今日の ToDo が 3 つ未満の最初の KDI (今の `nextHierarchyStep` の todo の部分)
- `threadAllowsChange(thread, ref)`: kpi は K だけ・kdi は D だけ・ほかは変えない
- 判定 (EXP-034) は todo だけ・仮説 (EXP-032) はどの会話でも

`/api/coach`: 本文の `thread` (無ければ chat)。その会話の履歴だけを読み・保存する。プロンプトの「次に決める段」と足せる・変えられるものは `threadStep` / `threadAllowsChange` に従う。会話ごとの役割の文 (下の表) を入れる

| 会話 | 役割の文 (プロンプト) |
|---|---|
| chat | 何でも相談できる壁打ちの相手。悩みや考えを整理し、必要なら KGI / KPI / KDI / ToDo のどのチャットで決めるとよいかを案内する |
| kgi | KGI (固定) の意味・進み具合・期限までの見通しを一緒に確かめる。KGI は変えない |
| kpi | KGI を期限までに達成できているかを測る KPI を決める・変える |
| kdi | KPI を達成するための KDI (行動の量・頻度) を決める・都度変える |
| todo | 今日の ToDo (時刻つき) を決める・完了したら判定する・振り返る |

画面: 会話の上にタブ「💬 壁打ち・相談」「🎯 KGI」「📈 KPI」「🧭 KDI」「✅ ToDo」「🆕 プロジェクト作成」(role="tab")。プロジェクトを選んでいなければ「🆕 プロジェクト作成」だけ。切り替えるとその会話の続きを読む。手帳の「AI と判定する」「今日の ToDo を決めたい」は ✅ ToDo の会話に送る
