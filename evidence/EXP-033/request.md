**この文書の数値・規則は、測った後で変えない。**

## 1. 仮説と範囲

- H1: 自分で棚上げ・調整と決めた ToDo を「できなかった」に数えなければ、できた割合が本人の実感に近くなり、判定で落ち込みにくい
- 範囲: `lib/progress.ts` の「できた割合」の分母だけ
- 範囲外: 内訳の表示 (棚上げ・調整の数は今まで通り出す)・ほかの集計

## 2. 決まり

- できた割合 = (実行 + 成功) / (実行 + 成功 + 失敗)
- 分母が 0 (失敗も実行も成功も無い) なら「できた割合 まだ無し」
- 内訳 (`(未実行 1・実行 1・失敗 1・棚上げ 1・成功 1・調整 1)`) は今まで通り全部出す
- EXP-032 の「分母 = 未実行以外」を本カードで置き換える (EXP-032 の request.md は変えない)

## 3. 実験室の判定

| 規則 | 条件 |
|---|---|
| L1 | 実行 1・成功 1・失敗 1・棚上げ 1・調整 1 → できた割合 67% (2/3)・内訳に棚上げ 1 と調整 1 が出る |
| L2 | 棚上げと調整だけ → 「まだ無し」 |
