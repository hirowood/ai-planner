# EXP-042 事前登録 — 手帳にノート (仮説・検証結果) を入れる

Status: **登録済み (変更より前の commit)** / Date: 2026-10-02
仕様: `docs/product-spec.md` §0 (A: 調整で仮説を立てる・データを取る)
きっかけ: 本人「手帳にノートを、仮説や検証結果を入れるノートを入れてください」
**この文書の数値・規則は、測った後で変えない。**

## 1. 仮説と範囲

- H1: 振り返る場所 (手帳) で仮説と検証結果を書いて見返せれば、「仮説 → やってみる → 検証結果 → 次の仮説」のつながりが 1 か所で分かり、改善が続く
- 範囲: ノートの欄を プロジェクトの中のタブから 手帳 へ移す・ノートの種類に「仮説」「検証結果」を足す (既定の選択は「仮説」)・種類で絞る (すべて / 仮説 / 検証結果)
- 範囲外: AI が検証結果を自動で書く・仮説と検証結果を結びつける

## 2. 決まり

- 種類の値は「仮説」「検証結果」(文字のまま保存・AI が残す「仮説」(EXP-032) と同じ値)。今までの 事実 / データ / 考え / その他 はそのまま
- 手帳の欄の並び: 手帳 (日・週・月) → 📓 ノート (仮説・検証結果) → これまでのデータ
- 絞り込み: 「すべて」「仮説」「検証結果」(aria-pressed)。件数を出す
- プロジェクトの中のタブは ✅ タスク・📝 Plan の 2 つ (ノートは手帳へ)

## 3. 実験室の判定

| 規則 | 条件 |
|---|---|
| L1 | ノートの種類の選択肢に 仮説・検証結果 (既定は仮説)・保存する値は「仮説」「検証結果」 |
| L2 | 絞り込み: すべて / 仮説 / 検証結果 で一覧が変わる・件数 |
| L3 | 手帳の欄にノート・プロジェクトの中のタブからノートが無い |
| L4 | `npm test` 全件成功・`tsc` 0・eslint 0 errors・`next build` 成功 |

| 判定 | 条件 |

| **巻き戻し** | ノートが見つからない・消えた、と本人が報告した (Human Gate) |
