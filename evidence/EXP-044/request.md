# EXP-044 事前登録 — 会話の質を上げる: チャットによってモデルを分ける・返答の形と繰り返しの禁止

Status: **登録済み (変更より前の commit)** / Date: 2026-10-02
きっかけ: 本人「出力結果や会話内容の質を上げてください」。本人の選択: **チャットによって分ける** (壁打ちと KGI / KPI の相談とプロジェクト作成は上位のモデル、回数の多い KDI と ToDo は今のモデル)
**この文書の数値・規則は、測った後で変えない。**

## 1. 仮説と範囲

- H1: 考えを深める会話 (壁打ち・KGI・KPI・作成) に上位のモデルを使い、すべての会話で返答の形をそろえ、同じ質問の繰り返しを禁じれば、本人の点数が上がり、同じ質問が続くことが減る
- 範囲: モデルの選び方・上位のモデルが使えないときは今のモデルに替えて 1 回だけ送り直す・返答の形の文・繰り返しの禁止と測り方
- 範囲外: 別の AI の会社のモデル・料金のかかる枠

## 2. 決まり

`lib/model.ts`:
- `GEMINI_MODEL` (今の gemini-3.5-flash-lite・KDI / ToDo / 古い会話)・`GEMINI_MODEL_DEEP` (上位: gemini-3.5-flash・chat / kgi / kpi / 作成)
- `modelFor(thread)`・上位のモデルが 404 (無い) / 429 (枠切れ) なら今のモデルで 1 回だけ送り直す (`withModelFallback`)・`[perf]` に `model_fallback` (真偽)
- 上位のモデルは **実際に 1 回呼んで 200 を確かめてから** 使う (EXP-014 の教え)。確かめる道具 `scripts/probe-model.mjs` (キーも中身も出さず、状態の数だけ出す) を本人が実行する。確かめるまでは上位を使わない設定 (`DEEP_MODEL_VERIFIED = false`) で出す

返答の質 (すべての会話のプロンプト):
- 返答の形: ①受け止め (ユーザーの言葉を短く言い換える) ②記録に基づく所見 (根拠の記録を 1 つ添える) ③提案を 1 つ (候補はボタンに) か質問を 1 つ。300 字まで
- **直前の自分の質問と同じ質問をしない**。ユーザーが答えたら、確かめ直さずに次へ進む
- 具体的に: 数・期日・時刻・回数で言う。記録に無い数字は作らない
- `[perf]` に `question_repeat` (真偽: 返答の最後の質問が、直前の自分の返答の質問と同じか・空白と記号を除いて比べる)
